# GenshinImpact-Mod-MC-26.3-Java-Fabric

**新坤的原神角色** —— 把七位《原神》角色作为会生活、会战斗的 NPC 带进 **Minecraft Java 版 26.3（Fabric）**。

他们使用完整的骨骼蒙皮模型渲染，会眨眼、说话、走路、挖矿、伐木、捡东西、吃饭、开门，也会在遇敌时拿出真正趁手的武器反击。角色、语音、手办、建筑蓝图与专属道具都打包在同一个模组里，客户端与服务端通用。

## 环境要求

| 项目 | 版本 |
| --- | --- |
| Minecraft | **26.3** |
| 模组加载器 | Fabric Loader **0.19.5** 或更高 |
| 前置模组 | Fabric API **0.163.0+26.3**（或同版本更新的 26.3 构建） |
| Java | **25** |
| 运行端 | 客户端与服务端均可（`environment: "*"`） |

> 26.x 使用 Mojang 官方未混淆名与 Java 25，与 1.21.x 的构建体系不同；本模组不能装到 1.21.x 或其他加载器上。

## 安装

1. 为 Minecraft 26.3 安装 Fabric Loader（0.19.5+）。
2. 把 [Fabric API](https://modrinth.com/mod/fabric-api) 与本模组的 `xinkun-genshin-mod-1.0.0.jar` 一起放进 `.minecraft/mods`。
3. 启动游戏。创造模式物品栏会多出四个分栏：
   - **新坤的原神角色**：七枚刷怪蛋
   - **新坤的原神道具**：月饼、翠叶书卷、七款角色手办
   - **新坤的原神建筑（通用）**：现代别墅、城市高楼、中世纪建筑等
   - **新坤的原神建筑（角色）**：各角色的专属建筑
4. 专用服务器：安装 Fabric Loader 与 Fabric API 后放入同一个 jar 即可；渲染相关内容只在客户端加载。

### 通用行为

- **骨骼渲染**：七位角色均使用导出的骨骼与蒙皮模型（XKM），由原版动作系统驱动，叠加眨眼、说话口型与布料摆动。
- **动作过渡**：攻击沿用原版 `SwingAnimation` 模板（劈砍 / 突刺 / 施法），再叠加角色专属姿势；所有叠加偏移以 `sin(πp)`、`sin(2πp)` 加权，起手与收势均为零并与下一段动作交叉混合，不会出现跳帧。
- **采集工作**：会寻找自然树木整棵放倒并补种树苗，也会逐块挖掘矿脉；镐与斧在整套挥击播放完毕后才收回背包。
- **战斗**：被生物袭击后会追击反击；面对强力敌人会自动换上全套下界合金盔甲，脱战后收起。战斗武器为原版物品（弓、下界合金矛、下界合金剑、附魔书、翠叶书卷），不做凭空光束。
- **生存作息**：完整昼夜作息、开门、按按钮/拉杆、拾取、进食；非战斗状态每秒恢复最大生命值的 5%。
- **死亡与重生**：死亡后在刷新点复活，重生队列随存档持久化，即使中途关服也不会永久消失。
- **语音与字幕**：使用游戏官方中文语音，所有台词带头顶气泡；天气变化、问候、战斗与施法都有对应语音。
- **成就**：首次击败任意一位原神角色会获得成就 **「原神怎么你了！！！」**。

## 道具与建筑

### 角色手办（7 款）

- 右击方块摆放，左键敲掉即可回收。
- 无碰撞的装饰方块，支持 16 向朝向，可摆在桌面、展柜或底座上。

### 建筑蓝图道具（59 件）

- 分为「通用」与「角色」两个分栏，涵盖现代别墅、城市高楼、中世纪城堡、璃月古建、须弥建筑、月球基地等。
- 手持道具**右击任意方块**，建筑会从点击位置向上逐层落成；朝向跟随玩家面向自动旋转 90°。
- 创造模式不消耗道具，生存模式每次消耗 1 个。
- 施工为强制放置：不检查地形与实体，落在生物身上的方块会把它们顶到上方。

### 其他道具

- **「少女」的月饼**：食用后回满生命，并获得十五分钟的全套增益。
- **翠叶书卷**：纳西妲同款法器，翻页横扫身边六格内的敌人。

## 从源码构建

### 前置

- **JDK 25**（`JAVA_HOME` 指向它）
- 可访问 Minecraft 资源与 Maven 仓库的网络
- 无需手动配置 mappings：26.x 直接使用官方名

### 构建

```bash
git clone https://github.com/akun666yyds/GenshinImpact-Mod-MC-26.3-Java-Fabric.git
cd GenshinImpact-Mod-MC-26.3-Java-Fabric

# Linux / macOS
./gradlew build

# Windows
gradlew.bat build
```

构建产物：

```
build/libs/xinkun-genshin-mod-1.0.0.jar
```

### 本地调试

```bash
./gradlew runClient   # 启动带模组的客户端
./gradlew runServer   # 启动带模组的专用服务器
```

首次运行会下载 26.3 的游戏资源与依赖，耗时取决于网络。

> 项目在 `gradle.properties` 中默认使用 **BMCLAPI 镜像** 下载 Mojang 资源（`loom_libraries_base`、`loom_resources_base`、`loom_version_manifests`）。如果你在海外或镜像访问不畅，可以把这三行改回官方地址或直接删除。

### 目录结构

```
src/main/java      服务端与通用逻辑（角色 AI、实体、物品、方块、建筑）
src/main/resources 资源与数据（模型、贴图、语音、语言文件、结构蓝图）
src/client/java    客户端渲染（骨骼模型、渲染器、粒子、界面）
gradle.properties  版本与镜像配置
```

### 技术要点

- Minecraft **26.3** + Fabric Loader + Loom 1.18，Java 25，Mojang 官方名。
- 角色外观由导出的骨骼与蒙皮数据实时蒙皮（CPU 线性混合蒙皮），并按实体逐帧平滑。
- 攻击使用原版 `SwingAnimation` 类型与时长，再叠加逐角色姿势；行走、待机、施法与采集姿势通过权重交叉淡入。
- 所有注册内容均走 Fabric/原版注册表，客户端渲染代码隔离在 `src/client`。
